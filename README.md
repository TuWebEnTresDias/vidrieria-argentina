# Vidriería Argentina

Sitio estático de una página para GitHub Pages, sin dependencias ni proceso de build. La web está en `index.html`.

## Datos incorporados desde el registro del lead

- Nombre: Vidriería Argentina.
- Zona: Mar del Plata Centro.
- Horarios: lunes 8:30–18:30; martes a sábado 8:30–20:30; domingo cerrado.
- El contacto principal abre WhatsApp y prepara un mensaje que la persona revisa antes de enviarlo.

No se agregaron servicios específicos porque todavía no están detallados en el chat o en el registro.

Pages no está activado todavía. Para habilitar la vista previa: `Settings → Pages → Deploy from a branch → main → /(root)`. Después, verificar que la URL pública cargue antes de compartirla como publicada.
